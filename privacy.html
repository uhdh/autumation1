사용자가 입력한 조건과 메모

구매 화면의 예산·현금·대출·장소·이동조건·비교 메모는 브라우저에서 계산하며 서비스 서버로 전송하지 않습니다. 회원가입·결제·사용자 분석 도구는 사용하지 않습니다.

기본값은 임시 보관입니다. ‘이 기기에 내 조건·비교 노트 저장’을 켜면 일부 조건과 비교 노트를 해당 브라우저 localStorage에 보관합니다. 자동 만료는 없으며, 저장을 끄거나 ‘내 입력 전체 지우기’를 누르거나 브라우저 사이트 데이터를 삭제하면 지워집니다. 단지 필터와 자동 출퇴근 조건은 이 화면에서만 유지됩니다. 공용 기기에서는 저장하지 마세요.

접속 시 외부로 전달되는 정보

페이지와 공개 자료는 Cloudflare Pages에서 제공됩니다. 접속에 필요한 IP 주소·요청 URL·브라우저 정보 등이 호스팅 사업자에게 전달될 수 있습니다. 지도 SDK와 배경 지도는 카카오 서버에 요청하며 IP 주소·브라우저 정보·표시한 지도 영역에 해당하는 타일 주소가 전달됩니다. 개인 예산이나 메모는 타일 요청에 넣지 않습니다. 기기의 GPS 위치 권한은 요청하지 않습니다.

기존 엑셀 화면에서 거래·뉴스를 조회하면 지역·계약월 또는 지역 검색어를 서비스 API에 보내고, API는 공공데이터·뉴스 제공자에게 조회합니다. 외부 사이트 링크를 열거나 GitHub에 오류를 제보하면 해당 서비스의 정책이 적용됩니다.

보관·문의

이 앱은 사용자 입력을 보관하는 서버 데이터베이스를 운영하지 않습니다. 호스팅·지도 제공자의 접속 로그 처리는 각 제공자의 정책에 따르며 앱에서 직접 삭제할 수 없습니다. 이 프로젝트가 별도로 수집하는 분석 로그는 없습니다.
