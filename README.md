# 우리집 찾기 · 엑셀아파트

> 가격 범위와 생활 조건으로 서울 아파트 후보를 좁히는 구매 탐색 서비스. 기존 엑셀 화면도 제공합니다.

운영: https://excelzip.pages.dev/ · 기존 화면: /excel.html · [출시·갱신·복구 안내](RELEASE.md)

Microsoft Excel 스프레드시트 UI를 위장 껍데기로 사용하고, 실제 콘텐츠는 국토교통부 아파트 실거래가 데이터를 보여줍니다.

## 기능

- **우리집 찾기** (`/buy.html`): 구매 예산 설정, 지역·면적별 실거래 후보, 최대 3개 비교, 매물 가격·수리비·월 상환 시나리오, 가족 거점별 수동 이동시간과 메모
- 기본 탐색: **서울 전체 · 대출 가정 6억 + 현금 4억 = 집값 10억 이하**, 최근 3개월 공개 거래 스냅샷 자동 표시. 부대비용·비상금 미반영. 추가 재무·가족 조건은 필요할 때만 펼침
- 개인 입력은 기본 임시 보관이며, 선택 시 브라우저에만 저장. 전세가율·최고가 상승률·자체 상대평가와 1~8호선 기반 출퇴근 추정을 제공. 현재 매물 수집·실시간 길찾기는 미제공
- Excel 리본 UI 위장 (제목표시줄, 시트 탭 포함)
- 관심 아파트 단지 검색 및 실거래가 조회
- 단지별 준공년월 · 세대수 표시 (`seoul_apt_complex.json` 정적 매칭)
- 서울 지역구별 법정동 코드(`seoul_lawd_codes.json`) 내장

## 기술 스택

| 레이어 | 사용 기술 |
|--------|-----------|
| 프론트엔드 | 바닐라 HTML/CSS/JS (빌드 불필요) |
| 백엔드 | Cloudflare Pages Functions |
| 데이터 | 국토교통부 공공데이터포털 아파트 실거래가 API |
| 캐싱 | Cloudflare KV (선택) |

## 로컬 실행

키 없이 구매 화면 확인(구매 화면은 정적 공개자료, 엑셀 화면 거래·뉴스는 기존 공개 배포 API 사용):

```bash
node dev.mjs
# http://127.0.0.1:8789/buy.html
```

이 서버는 로컬 화면 검토용이며 수정한 Functions를 실행하지 않습니다. Functions는 아래 wrangler 또는 자동 테스트로 확인하세요.

```bash
# Cloudflare Pages 로컬 개발 서버 (wrangler 필요)
npx wrangler pages dev . --binding APT_SERVICE_KEY=<your_key>
```

또는 `index.html`을 브라우저에서 바로 열면 됩니다 (API 프록시 없이 UI만 확인 — 노란 경고 표시줄과 함께 샘플 데이터가 표시됨).

## 배포 (Cloudflare Pages)

1. 이 저장소를 Cloudflare Pages에 연결
2. **환경 변수** 설정:
   - `APT_SERVICE_KEY` — 공공데이터포털에서 발급받은 서비스키 (URL 인코딩된 원본값, `%2B` 등 포함)
3. (선택) **KV 네임스페이스** 생성 후 바인딩 이름 `APT_CACHE`로 연결

## API 엔드포인트

```
GET /api/apt-trade?lawdCd={5자리}&dealYmd={YYYYMM}
```

| 파라미터 | 형식 | 예시 |
|----------|------|------|
| `lawdCd` | 서울 법정동코드 5자리 (`11`로 시작) | `11680` (강남구) |
| `dealYmd` | YYYYMM | `202605` |

거래가 많은 구·월도 누락되지 않도록 상위 API의 `totalCount`에 닿을 때까지 페이지를 넘겨 전부 가져옵니다.

```
GET /api/apt-news?query={자치구} 부동산
```

네이버 뉴스 검색 프록시. `서울 부동산` 또는 `<서울 25개 자치구> 부동산`만 허용합니다 (환경 변수 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` 필요).

## 세대수·준공년도 데이터

국토교통부 아파트매매 실거래자료 API에는 세대수 항목이 없어, K-apt(공동주택관리정보시스템)에서 제공하는
전국 단지 기본정보 엑셀(로그인·인증 불필요, `https://www.k-apt.go.kr/web/board/goKaptBasicExcelDownload.do`)을
내려받아 서울 25개구만 추려 `seoul_apt_complex.json`으로 정적 가공해 두었다 (최초 기준일 2026-07-03, 최신 게시물 자동 갱신).
실거래가 API의 단지명(`aptNm`)과 이 파일의 단지명(`kaptName`)을 정규화 후 매칭해 세대수·준공년도를 표시한다.
같은 구·법정동(`umdNm`/`dong`) 안에서 유일하게 매칭되는 단지만 사용한다. 이름이 모호하거나 매칭되지 않는 단지는 목록에서 제외된다.
스냅샷은 시간이 지나면 낡으므로, GitHub Actions에서 최신 공개 게시물을 수집한다.

### 구매 화면 지도

`buy.html`은 카카오맵 Web SDK를 사용한다. `bike_map`과 같은 카카오 앱의 브라우저 공개 JavaScript 키를 사용하며 무료 쿼터를 공유한다. 허용 도메인은 카카오 개발자 콘솔에서 관리한다: `https://excelzip.pages.dev`, `https://release-buyer.excelzip.pages.dev`, `http://127.0.0.1:8789`. 다른 배포 주소는 SDK 도메인 등록이 필요하다. REST/어드민 키는 프런트엔드에 넣지 않는다. SDK 공식 문서: https://apis.map.kakao.com/web/documentation/ .

좌표는 [서울특별시 공동주택 아파트 정보](https://data.seoul.go.kr/dataList/OA-15818/A/1/datasetView.do)의 공개 JSON 내려받기 자료를 2026-10-22에 가공한 `seoul_apt_locations.json`이다. 공공누리 제1유형(출처 표시) 자료이며, 원본 2,894행에서 사용 중인 단지의 유효 서울 범위 좌표 2,854행만 추렸다. 단지코드·이름·구·동·도로명주소·좌표만 보관한다. 갱신 시 원본 화면의 JSON 내려받기로 다시 받아 동일 필드를 추출한다.

K-apt의 구·동·지번 및 준공연도를 확인한 뒤 공식 단지코드로 좌표를 연결한다. 중복 필지나 주소 불일치는 제외한다. 이름 변경이나 미등록 단지는 위치 미연결로 목록에 남으며, 지도상의 점은 공개 자료의 단지 대표 좌표다. 예산·면적 조건은 목록과 지도에 함께 적용한다. 한 단지의 여러 면적은 같은 점의 팝업에서 고를 수 있다. 개인 장소나 재무 입력은 타일 서버에 전송하지 않는다.

검증: `node --test tests/*.test.mjs` (11개), 브라우저의 지도↔후보 이동·예산 변경·390px 너비 표시 확인. 구매 화면은 수집일이 표시되는 거래 스냅샷을 사용한다. 엑셀 화면은 기존 거래 API를 사용한다. 출시 절차와 검증 기록은 RELEASE.md를 참고한다.


## 구매 분석 데이터 갱신

```powershell
node scripts/build-market-data.mjs --refresh
node --test tests/*.test.mjs
```

- 서울시 매매 OA-21275, 전월세 OA-21276의 공개 JSON 내려받기와 서울교통공사의 역간시간 OA-12034, 역좌표 OA-22534 CSV를 사용한다. 공공누리 제1유형 자료로 화면에 출처를 표시한다.
- 원본은 `.data-cache/`에 저장하며 Git에서 제외한다. 분석용 `market-data.json`(약 7.5MB)과 `rail-data.json`을 생성한다. `--refresh` 없이 실행하면 캐시로 재집계하며 실제 수집일을 유지한다. `--as-of=YYYYMMDD`는 원본 수집일까지의 재현용이다.
- 2026-10-22 원본: 매매 196,157행, 전월세 171,898행. 최근 거래가 있는 11,647개 단지·면적 정수 그룹에 전세가율 3,258개, 3개월 상승률 1,225개, 유효 상대평가 189개를 계산했다. 목록은 정확한 전용면적별로 분리하므로 지표 그룹 수와 다르다.
- 매매 취소·권리 거래는 수집 단계에서 제외한다. 지표 계산은 중개거래·5층 이상으로 제한한다. 전월세는 월세 0인 전세만 집계하며 갱신도 포함한다. 원자료에 전세 취소 식별 필드가 없어 취소 제거를 보장하지 않는다.
- 상대평가는 2024/2025년 4분기 최고가를 사용한 자체 비교다. 2020~2022년 전고점 및 2023년 전저점은 미수집이며 원 사이트의 서버 알고리즘을 재현했다고 주장하지 않는다. 같은 면적 정수부·과거가 ±5% 후보의 상대 가격 격차를 ±1%p로 판정하며, 중앙값/최고가 판정 혼재를 제외한 비교 3개 이상일 때 점수를 낸다. 세대수·입지·연식 보정은 하지 않는다.
- 출퇴근은 공식 CSV의 연결 구간만 사용한다. 2/5호선 지선과 6호선 응암 단방향을 구분한다. 환승 5분, 대기/직장역 도보 여유 10분, 직선거리 우회계수 1.3이 기본이며 사용자가 변경할 수 있다. 좌표가 없는 암사역사공원 연결은 제외한다. 9호선·신분당선·코레일·버스 및 실시간 운행은 미포함이다.
- 저장 옵션은 재무·비교 노트에 적용한다. 자동 출퇴근 역 필터는 세션 내 임시 상태이며 새로고침 시 초기화된다.
- `market-data.json` 갱신은 위 스크립트를 실행해야 한다. 사이트가 자동으로 매일 갱신되는 상태는 아니다. 배포 시 원본 `.data-cache/`, 테스트, 도구 코드를 올리지 말고 정적 공개 파일과 Functions만 배포한다.
- 검증: 16개 Node 테스트, 실제 브라우저에서 상대평가 근거·부부 직장역 필터·지도 동기화·390px 가로 넘침 없음 확인. 공개 사이트 배포는 아직 하지 않았다.
# 구매 화면 필터 (로컬 구현)

`http://127.0.0.1:8789/buy.html`에서 최소~최대 가격(기본 0~10억)을 바로 바꿀 수 있습니다. 대단지(선택 시 기본 1,000세대), 초품아 참고목록, 역까지 직선거리, 연식은 교집합으로 지도와 목록에 즉시 적용됩니다. 조건에 필요한 정보가 없으면 제외하며, 남은 지도 점과 현재 지도 위치는 유지합니다. 초품아는 비공식 목록이고 역세권은 수도권 역사마스터를 사용하고 출퇴근 시간은 1~8호선 일부 구간을 사용합니다.

검증: Node 17개 테스트 통과. 브라우저에서 가격 7~9억 → 1,000세대 → 역 500m 순서로 지도 단지 83 → 14 → 1개, 역전된 가격 범위의 오류 표시, 조건 해제 후 복원, 390px 화면 가로 넘침 없음을 확인했습니다. 출시 및 운영 상태는 RELEASE.md를 참고하세요.
